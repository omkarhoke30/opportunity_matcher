# 🎯 Opportunity Matcher

**Opportunity Matcher** is a full-stack web application designed to help students discover and explore opportunities such as **internships, hackathons, competitions, workshops, scholarships, jobs, and events** in one place.

The platform provides separate experiences for students and administrators, with authentication, student profiles, opportunity management, applications, and saved opportunities.

## 🚀 Live Demo

[visit my website](https://opportunity-matcher.onrender.com)

## ✨ Features

* 🔐 Student and admin authentication
* 👤 Student profile management
* 🎓 Education, skills, interests, and projects
* 🔎 Browse and explore opportunities
* 📄 Detailed opportunity information
* 📝 Opportunity applications
* 🔖 Save opportunities
* 🛠️ Admin opportunity management
* 🔒 Role-based access control
* 📱 Responsive user interface

## 🔒 Security

Sensitive configuration and credentials are kept outside the public repository.

The following are **not included in the repository**:

* Database credentials
* JWT secrets
* Environment variables
* Private API keys
* Admin credentials
